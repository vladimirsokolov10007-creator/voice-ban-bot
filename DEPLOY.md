# Деплой бота на Koyeb (бесплатно, без карты)

Архитектура облачного варианта:

```
голосовой канал ──> бот на Koyeb (Node.js, ~300 МБ RAM)
                        │ PCM каждой фразы
                        ▼
                   Groq API (whisper-large-v3-turbo, бесплатный тариф)
                        │ текст
                        ▼
                   наказание через Discord API
```

Python и модель Whisper на сервере не нужны — поэтому бот помещается
в бесплатный инстанс Koyeb. Регистрация в обоих сервисах — по email/GitHub,
банковская карта не требуется.

---

## Шаг 1. Ключ Groq (5 минут)

1. Откройте [console.groq.com](https://console.groq.com) и зарегистрируйтесь
   (через Google/GitHub — без карты).
2. В меню слева: **API Keys** → **Create API Key** → скопируйте ключ
   (начинается с `gsk_...`). Показывается один раз.

Бесплатный тариф даёт: 2000 запросов и до 8 часов аудио в день,
20 запросов в минуту — для сервера с друзьями этого хватает с запасом.

## Шаг 2. Локальная проверка облачного режима (2 минуты)

В файле `.env` в папке проекта добавьте две строки:

```
STT_ENGINE=groq
GROQ_API_KEY=gsk_ваш_ключ
```

Запустите `npm start`, зайдите в голосовой канал, `!слушать`,
произнесите фразу с «вась». В консоли должны быть строки
`[audio] конец фразы ... pcm=<большое число>` и `[stt] сессия #1: «...»`,
а в чате — нарушение. Задержка при этом будет около секунды.

Если всё работает — локальный Python больше не нужен вообще.

## Шаг 3. Репозиторий на GitHub (10 минут)

Koyeb собирает код из GitHub, поэтому проект нужно туда выложить.

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Создайте новый репозиторий: кнопка **New** → имя (например, `voice-ban-bot`)
   → **Private** → Create.
3. В папке проекта выполните (потребуется установленный [Git](https://git-scm.com)):

## Шаг 4. Деплой на Koyeb (10 минут)

1. Откройте [koyeb.com](https://www.koyeb.com) → **Sign up** (GitHub/email).
2. В панели: **Create Service** → **GitHub**.
3. Выберите репозиторий `voice-ban-bot` (при первом подключении Koyeb попросит
   доступ к GitHub — разрешите).
4. Koyeb сам найдёт `Dockerfile`. Проверьте настройки:
   - **Instance type**: Free (0.1 vCPU / 512 МБ) — для облачного режима достаточно;
   - **Region**: Frankfurt (`fra`) — ближе к голосовым серверам Discord в Европе;
   - **Port**: оставьте как есть (8000) — бот отвечает health-check'ом на нём.
5. В разделе **Environment variables** добавьте:
   - `DISCORD_TOKEN` = токен бота из Developer Portal;
   - `STT_ENGINE` = `groq`;
   - `GROQ_API_KEY` = ваш ключ `gsk_...`.
6. Нажмите **Deploy** и подождите 2–3 минуты сборки.
7. Откройте вкладку **Logs** — там должно быть:

```
STT: облачный Groq, модель «whisper-large-v3-turbo».
Бот запущен как Voice_Ban#1222
Health-check на порту 8000
```

## Шаг 5. Проверка

В Discord: бот должен быть «в сети» постоянно (даже при выключенном ПК).
Зайдите в голосовой канал → `!слушать` → фраза с «вась» → нарушение.

После этого локальный `npm start` на вашем ПК больше не запускайте:
два экземпляра бота будут отвечать на команды вдвойне
(мы уже наступали на эти грабли).

## Ограничения и нюансы

- **Лимиты Groq**: 8 часов распознанной речи в день, 20 фраз в минуту.
  При превышении бот напишет в лог `лимит исчерпан (HTTP 429)` — наказания
  просто не сработают до сброса лимита, бот не упадёт.
- **Приватность**: фразы участников отправляются в сторонний сервис (Groq, США).
  Предупредите участников сервера. Если это неприемлемо — оставайтесь
  на локальном движке (`STT_ENGINE=local`) на своём ПК или VPS.
- **Бесплатный инстанс Koyeb** один на аккаунт; боту хватает, но если
  когда-нибудь захотите вернуть локальный Whisper — бесплатных 512 МБ
  не хватит, понадобится платный инстанс или VPS.

## Если что-то пошло не так

| Симптом | Причина |
|---|---|
| В логах Koyeb `Движок «groq» требует GROQ_API_KEY` | Не добавлена переменная окружения `GROQ_API_KEY` |
| `[stt] ошибка Groq: HTTP 401` | Ключ скопирован не полностью или отозван — создайте новый |
| `[stt] ошибка Groq: HTTP 429` | Дневной/минутный лимит исчерпан, подождите сброса |
| Бот «в сети», но не заходит в голосовой канал | Смотрите `[voice] ...` в логах Koyeb; обычно помогает повторная команда `!слушать` |
| Сервис перезапускается | Нехватка памяти — убедитесь, что `STT_ENGINE=groq` (режим local не влезает в 512 МБ) |
