# Голосовой модератор для Discord

Бот слушает голосовой канал, распознаёт речь и наказывает за запрещённые
слова. По умолчанию бан-слово — **«вась»** (с префиксным совпадением ловит
и «ваську», «васька» и т.п.).

Два движка распознавания (переключается `STT_ENGINE` в `.env`):

- **groq** — облачный Groq API, бесплатно и без карты; не требует ни Python,
  ни мощного компьютера, работает на слабом бесплатном хостинге.
  См. [DEPLOY.md](DEPLOY.md).
- **local** — локальный Whisper (faster-whisper) на вашей машине;
  приватнее, но нужен Python и приличный CPU/GPU.

Эскалация наказаний (настраивается в `config.js`):

1. предупреждение в текстовый канал
2. тайм-аут на 60 секунд
3. тайм-аут на 10 минут
4. кик с сервера

## Как это работает

```
голосовой канал ──Opus 48k──> @discordjs/voice ──> opusscript (декодирование)
    ──> ffmpeg (ресемплинг 48k стерео → 16k моно) ──> Python-воркер (faster-whisper)
    ──> текст ──> поиск бан-слова ──> наказание через Discord API
```

- Node.js-часть (`index.js`) — подключение к каналу, приём аудио, команды, наказания.
- Python-часть (`stt_worker.py`) — один долгоживущий процесс с загруженной моделью
  Whisper; аудио каждой фразы накапливается и распознаётся по завершении.

## Требования

- Node.js 18+
- Python 3.10+
- Windows/macOS/Linux

## Настройка бота в Discord

1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен.
3. Там же включите **Message Content Intent** (раздел Privileged Gateway Intents).
4. Вкладка **OAuth2 → URL Generator**: scope `bot`, права как минимум
   `Connect`, `View Channels`, `Send Messages`, `Moderate Members`
   (для тайм-аутов), `Kick Members` (для кика). Откройте полученную ссылку
   и добавьте бота на сервер.
5. Роль бота в настройках сервера должна быть **выше** ролей участников,
   которых он будет наказывать, иначе тайм-аут/кик не сработает.

## Установка

```bash
npm install

python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt   # Windows
# source .venv/bin/activate && pip install -r requirements.txt   # macOS/Linux
```

При первом запуске faster-whisper сам скачает модель `small` (~460 МБ).

Создайте `.env` по образцу `.env.example` и вставьте токен:

```
DISCORD_TOKEN=ваш_токен
PYTHON_PATH=.venv/Scripts/python.exe
```

## Запуск

```bash
npm start
```

## Команды

| Команда | Действие |
|---|---|
| `!слушать` | Бот заходит в ваш голосовой канал и начинает модерацию |
| `!стоп` | Отключить прослушивание и выйти из канала |
| `!нарушения` | Показать счётчики нарушений |
| `!сброс @user` | Обнулить счётчик пользователя (без упоминания — всех) |
| `!слова` | Показать список запрещённых слов |

## Настройка

Всё в `config.js`:

- `banWords` — список запрещённых слов (по умолчанию `['вась']`);
- `matchMode` — `'prefix'` (ловить формы слова) или `'exact'` (только точное совпадение);
- `punishments` — цепочка наказаний: `warn`, `timeout`, `mute`, `disconnect`, `kick`;
- `whisperModel` — `tiny`/`base`/`small`/`medium`: больше модель = точнее и медленнее;
- `whisperDevice` — поставьте `cuda`, если есть NVIDIA GPU (заметно ускорит работу).

## Известные ограничения

- Задержка: наказание происходит через ~1–3 секунды после конца фразы
  (Whisper не потоковый — распознаёт законченную фразу).
- Нагрузка: каждая одновременно говорящая персона — отдельная сессия распознавания;
  на CPU `small` комфортно тянет несколько говорящих, для больших каналов нужен GPU.
- Whisper иногда «додумывает» текст в шуме — включённый VAD-фильтр это смягчает,
  но ложные срабатывания возможны, поэтому первая ступень наказания — предупреждение.
- Бот слышит только тех, кто не заглушил себя на уровне сервера... наоборот:
  бот слышит всех, но сам должен быть подключён с `selfDeaf: false` (уже настроено).
- Распознавание голоса — обработка персональных данных: предупредите участников сервера.
